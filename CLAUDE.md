# Languages & Success (L&S) — contexte projet

Site marketing + **espace documents** pour un organisme de formation en langues (Nice, certifié Qualiopi). FR. Itérations rapides, style éditorial chaud (rose-gold).

## Stack
- Front : **HTML/CSS/JS statique, sans framework**. CSS partagé `assets/site.css`. Nav/footer injectés par `assets/partials.js`. **Polices auto-hébergées** (`assets/fonts.css` + `assets/fonts/`) : aucune requête vers Google, cf. section Conformité.
- Back : **Node + Express** (`server.js`) qui sert le site **et** une API REST. Base = fichier **`data/db.json`** + fichiers dans **`data/uploads/`**. Auth bcrypt + JWT (token en `localStorage` côté client).
- **Robustesse DB** (`loadDB`/`save`/`backupDB`) : mots de passe **hachés bcrypt** (jamais en clair) ; **écriture atomique** (`.tmp` + `fs.renameSync`, pas de fichier à moitié écrit si crash) ; **sauvegardes horodatées rotatives** dans `data/backups/` (snapshot au démarrage + toutes les 6 h, 60 max ≈ 2 semaines) ; **auto-restauration** depuis le backup valide le plus récent si `db.json` est corrompu/illisible (sinon base neuve). `save()` appelé à chaque mutation = sauvegarde permanente. (Migration SQLite = piste future si besoin de concurrence/chiffrement au repos.)
- Anim héros : `morph.js` (canvas 2D, nuage de particules + logo). `medallion.js`/`sphere.js`/`worldmap.js`/`painting.js` = en réserve, non chargés.
- **i18n (langue du site)** : sélecteur dans le header (pastille `FR ▾` desktop, grille dans le drawer mobile), langues FR (source) / EN / ES / IT / RU / ZH. Moteur `assets/i18n.js` (injecté par `partials.js` comme account.js) : dictionnaires « texte FR normalisé → traduction » appliqués aux nœuds texte + attributs (placeholder/title/aria-label/alt), MutationObserver pour le DOM injecté, persistance `localStorage 'ls-lang'`, `<html lang>` mis à jour, retour FR = restauration des originaux. **TOUT le site vitrine est traduit** : dictionnaires par langue dans `assets/i18n-{en,es,it,ru,zh}.js` (~300 clés chacun, chargés À LA DEMANDE par le moteur — un visiteur FR ne charge rien), couvrant chrome + index + formations (+ modal certifications de certs.js) + financement + entreprises + à-propos + contact + test (UI/niveaux) + blog + page espace-documents. L'**app espace-documents est traduite aussi** (~140 clés : auth, dashboard, dossiers/chat/canaux, notifications, picker + modales de génération, statuts QS/présence, dialogues) — les libellés composites (« Dossier — {nom} », « Séance N », « Bonjour {prénom} », textes de notifs stockés en base, titres numérotés du picker) restent FR par construction. Restent en FR : pages légales (CGV/mentions/confidentialité/RI, volontaire — la version française fait foi), les **documents générés** (serveur, toujours français), les explications de correction du test. ⚠️ selects du test : `value="Anglais"` etc. explicites (le texte affiché se traduit, la value FR pilote la banque de questions) ; formations.html capture le nom FR des langues avant traduction pour le lien `?lang=`. ⚠️ Les zones sous `data-i18n-skip` ne sont JAMAIS traduites — posé sur `#q-text`, `#opts`, `#res-correction` du test de niveau pour que les questions restent dans la langue TESTÉE quel que soit le changement de langue du site (même en plein test). ⚠️ **Zone « champs » `data-i18n-champs="<sélecteur>"`** (23/09/2026) : à l'intérieur, les éléments qui correspondent au sélecteur ne sont pas traduits, le reste l'est (exception possible par `data-i18n-ok`) ; sert aux fenêtres de document, voir « LES CHAMPS D'UN DOCUMENT RESTENT EN FRANÇAIS ».

## Lancer / arrêter
- **Port** : `process.env.PORT || process.argv[2] || 3000`. **Défaut = 3000** (aligné avec la prod) ; en **local on lance toujours sur 8000** : `node server.js 8000` → http://localhost:8000. (Sert site + API.) La preview MCP utilise 8011.
- Le port peut être passé en argument : `node server.js 8011`.
- Données sensibles bloquées par le serveur (`/data`, `node_modules`, `server.js`).
- ⚠️ Toujours **un seul** serveur Node sur un port donné (sinon il écrase `db.json`). Tuer le port avant de relancer.
